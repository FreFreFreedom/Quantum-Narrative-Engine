# Quantum Narrative Engine (FMCNS)

Private research/prototyping repo for the Fractal Mythic Consciousness Navigation System — a personal tool, not a public product.

## Contents

- `fmcns_map_prototype.html` — geographic map prototype. Open directly in a browser.
- `fmcns_film_corpus.html` — film recommendation engine prototype (list/card view + force-directed graph view). Open directly in a browser.
- `BUILD_STATUS.md` — current state, coverage tracker, known gaps, open threads. Check `git log` for history instead of a manual changelog.

## How this repo is maintained

Claude (via Cowork) commits and pushes to this repo after each work session. There is no separate versioned "status document" outside git — BUILD_STATUS.md is edited in place and tracked by commits.
